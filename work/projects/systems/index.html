Systems & Networks

Systems and networking work focused on high-throughput packet processing, including kernel-bypass networking with DPDK and network path discovery.

Ultra-Fast Packet Crafter

CDPDKLinuxUDP · ICMP

The idea

Picture every packet as a paper plane. Normally each plane stops at the kernel's post office: it gets copied, stamped and queued before it reaches the network card. DPDK lets a program talk to the NIC directly from user space, so the planes skip the post office entirely.

The same tool doubles as a traceroute. Each probe carries a time-to-live, a fuel gauge that loses a bar at every router. When the fuel runs out, that router mails back an ICMP postcard, and the next probe gets one bar more.

My contributions

  • Modified Blitzping to construct and transmit custom UDP packets in memory instead of TCP.
  • Extended the tool with a DPDK kernel bypass for zero-copy NIC access: hugepage-backed memory pools, poll-mode drivers and VFIO-PCI, all transmitting from user space.
  • Built a TTL-based traceroute with UDP probes and ICMP feedback (Time Exceeded, Destination Unreachable) for hop-by-hop path discovery, with per-hop RTT measurement.
  • Outperformed standard Blitzping with 4.5× higher packet throughput (~105k → ~472k packets/s) and 6.7× higher bit-rate (~23.7 → ~159 Mbps).
