tree-walk, like Jlox

A tiny expression language for show. Psylang itself is much bigger: closures, lambdas, user-defined types and more.

Psylang is a language I'm designing from scratch. Source text passes along a belt: a Flex lexer cuts it into tokens, an LALR(1) parser builds a tree, and then two more stations do the real work.

  • Semantic analyzer on the AST: precise scoping, type checks, return reachability and helpful diagnostics
  • TAC IR generator producing quadruples for arithmetic, control flow, functions and short-circuit logic
  • Supports closures, lambdas and user-defined types

Try ok = x > 0 && y < 10 to see short-circuit jumps, or use a variable nobody declared.

Jlox, the little sibling

A tree-walk interpreter in Java for the Lox language from Crafting Interpreters. It has a scanner, a recursive-descent parser, generated AST classes, runtime environments with variable assignment and block scoping, and both a REPL and file execution with syntax and runtime error reporting.

The "run it" station above works the same way: it walks the tree and evaluates each node.
