Compilers & Languages

Language implementation projects covering both approaches to running code: a compiler front end for a custom language, and a tree-walk interpreter for Lox.

Psylang: A Custom Programming Language

CFlexBison · LALR(1)Make

The idea

A compiler is a conveyor belt. Source text goes in one end. The lexer cuts it into tokens, and the parser stacks them into a tree.

The semantic analyzer checks that the tree makes sense: is b declared, do the types match, does every path return? Then the IR generator rewrites it as three-address code, small instructions with at most one operator each, ready for a back end.

My contributions

  • Designed the language and wrote its specification: a Flex lexer and an LALR(1) Bison parser supporting closures, lambdas and user-defined types.
  • Built an AST-based semantic analyzer enforcing precise scoping, type checks and return reachability, with diagnostics that point at the exact line and column.
  • Implemented a TAC IR generator producing quadruples for arithmetic, control flow, functions and short-circuit evaluation, with IR, symbol-table and type-table dumps.
  • Set up Make-based builds and test suites for the lexer, parser, semantic analyzer and IR, with automatic comparison against expected outputs.

Jlox: A Tree-Walk Interpreter for Lox

Javarecursive descentCrafting Interpreters

The idea

Jlox skips the compiler back end entirely. It parses Lox into a syntax tree and then walks the tree, evaluating each node as it goes: leaves first, then the operators above them, following the red numbers in the drawing.

Variables live in environments that nest like boxes, so an inner block can shadow an outer variable without ever touching it.

My contributions

  • Built a tree-walk interpreter in Java for the Lox language from Crafting Interpreters.
  • Implemented the scanner, a recursive-descent parser, and AST code-generation tooling in a clean package structure.
  • Implemented runtime environments with variable assignment and block scoping.
  • Supported both a REPL and file execution, with syntax and runtime error reporting.
